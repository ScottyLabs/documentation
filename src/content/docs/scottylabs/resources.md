Here is a comprehensive list of available resources for ScottyLabs members.

## Google Drive

ScottyLabs's [Google Drive](https://drive.google.com/drive/folders/0AGTPPYnbmAAzUk9PVA) is used for storing and sharing files like meeting notes, project documents, events planning, etc.

See [Google Drive README](https://docs.google.com/document/d/1nB3qKzbOm2zlJboR3wlBX1m1CM2jsGnxZVe0KmKnBpA/edit?tab=t.0#heading=h.xrnok7ys3q25) for more information, including permissions.

## GitHub

[ScottyLabs GitHub Organization](https://github.com/ScottyLabs) is used for storing and sharing code, documentation, and other resources.

Each project has its own repository and might have a wiki page that serves as the project's documentation.

## Notion

[Notion Wiki](https://www.notion.so/wiki-scottylabs/Wiki-22496192554c80939578d18e876b8abc) serves as the internal documentation tool. Accessible only to ScottyLabs leadership.

## Slack

[ScottyLabs Slack](https://scottylabs.slack.com/) is the primary communication platform.

[Internal documentation link](https://www.notion.so/wiki-scottylabs/Slack-2e196192554c802fb90efad9e3efd774).

### Slack Apps

Anyone can create Slack Apps! But you would need to request to have it installed to the ScottyLabs Slack.

Every internal Slack app must satisfy the following requirements:

- Has a short description on what it is.

- Has a long description including the DRI (directly responsible individual) and relevant information on how it was set up.

- Shared with the ScottyLabs Admin member.

## Discord
